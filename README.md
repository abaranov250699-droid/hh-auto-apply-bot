# HH.ru Auto-Apply & Job Hunter Telegram Bot 🚀

Умный Telegram-бот для автоматического отслеживания вакансий на **HH.ru**, генерации адресных сопроводительных писем с помощью нейросети и отправки откликов в 1 клик с iPhone.

## ✨ Возможности
- 📱 **100% управление через Telegram**: авторизация в HH.ru по SMS, настройка фильтра поиска, добавление резюме, редактирование сопроводительных писем прямо в чате.
- 🔔 **Push-уведомления на iPhone**: мгновенная доставка новых подходящих вакансий сразу после их публикации работодателем.
- 🤖 **AI-генерация сопроводительных писем**: сопоставление стека вакансии с вашим резюме для создания лаконичных и убедительных писем без штампов.
- ✏️ **Интерактивное редактирование**: возможность отредактировать письмо вручную в чате или попросить AI переписать его («сделай короче», «добавь опыт с FastAPI»).
- 🚀 **Отклик в 1 клик**: бот в фоновом режиме через браузерную автоматизацию (Playwright) заходит на HH.ru и отправляет отклик от вашего имени.
- 🛡 **Защита от дублей**: локальная база данных SQLite гарантирует, что вы никогда не получите одну и ту же вакансию повторно.

---

## 🛠 Структура проекта
- `main.py` — точка входа: запуск бота и фонового планировщика.
- `bot.py` — логика Telegram-бота (Aiogram 3), обработка команд, FSM-диалоги и интерактивные кнопки.
- `hh_browser.py` — браузерная автоматизация HeadHunter (Playwright): вход по телефону/SMS, сохранение сессии, сбор вакансий и отправка отклика.
- `ai_letter.py` — генерация и редактирование сопроводительных писем (Gemini API / адаптивный шаблонизатор).
- `scheduler.py` — фоновый мониторинг новых вакансий с регулярным опросом.
- `database.py` — хранилище настроек пользователей, резюме и истории вакансий (SQLite).
- `config.py` — конфигурация и пути.
